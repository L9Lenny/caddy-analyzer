Subcommands Reference

Detailed guide for caddy-analyzer CLI subcommands
Overview Installation Log Sources Subcommands Threat Detector TUI & HTML Reports

1. tail (Real-Time Colorized Viewer)

Streams and colorizes Caddy access log entries into clean terminal lines formatted with status badges, method, latency, payload size, IP, and User-Agent classification:

# Tail local log file
caddy-analyze tail /var/log/caddy/access.log

# Tail live Docker logs
caddy-analyze tail docker://my-caddy

2. top (Quick Metric Inspector)

Provides targeted rankings for specific log dimensions without printing a full report:

Dimension Description Example
path Top requested HTTP URIs / endpoints (default) caddy-analyze top /var/log/caddy/access.log
ip Top client IP addresses (useful for scrapers & DoS) caddy-analyze top ip /var/log/caddy/access.log
ua Top User-Agent strings caddy-analyze top ua /var/log/caddy/access.log
status Top HTTP response status codes caddy-analyze top /var/log/caddy/access.log -b status
bandwidth Top paths sorted by total byte bandwidth caddy-analyze top bandwidth access.log -t 20

3. diff (Comparative Analysis)

Compares two log files side-by-side to detect RPS shifts, 5xx error spikes, latency regressions, and new failing URIs between deployments:

# Compare baseline log vs target log
caddy-analyze diff baseline.log current.log

4. config (Persistent Configuration)

Manages default log source settings in local or global JSON config files:

# View active configuration and source
caddy-analyze config show

# Set local default log source (./caddy-analyzer.json)
caddy-analyze config /var/log/caddy/access.log

# Set global default log source (~/.config/caddy-analyzer/config.json)
caddy-analyze config docker://my-caddy --global

# Reset / remove configuration file
caddy-analyze config reset

5. guard & block / unban

Monitors streaming logs and automatically blocks offending IP addresses exceeding threshold limits in real time via iptables rules (requires sudo):

# Start automated firewall guard daemon
sudo caddy-analyze guard --limit 100 docker://my-caddy

# Manually block specific IP addresses
sudo caddy-analyze block 1.2.3.4 5.6.7.8

# Remove IP block from iptables
sudo caddy-analyze unban 1.2.3.4
