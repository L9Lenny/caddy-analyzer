Subcommands Reference

Complete technical specification for all caddy-analyzer subcommands
Overview Installation Log Sources Subcommands Threat Detector TUI & HTML Reports

1. caddy-analyze [source] (Core Analyzer)

Runs standard batch analysis over the specified log source, generating a terminal report with visual proportion bar graphs, status code distribution, latency percentiles (p50, p90, p95, p99), bandwidth metrics, and top client IPs/paths.

# Basic terminal analysis
caddy-analyze /var/log/caddy/access.log

# Filter only 5xx server error requests
caddy-analyze --5xx /var/log/caddy/access.log

# Exclude search engine crawlers and automated bots
caddy-analyze --no-bots /var/log/caddy/access.log

# Filter slow requests taking longer than 500 milliseconds
caddy-analyze --slow 500ms /var/log/caddy/access.log

2. tail [source] (Real-Time Colorized Viewer)

Streams and colorizes Caddy access log entries line-by-line into clean terminal output formatted with HTTP status badges, HTTP method, latency, payload byte size, client IP, and User-Agent classification:

# Stream local log file in follow mode
caddy-analyze tail /var/log/caddy/access.log

# Tail live Docker log stream
caddy-analyze tail docker://my-caddy

3. top [dimension] [source] (Quick Metric Inspector)

Provides targeted rankings for specific log dimensions without generating a full report:

Dimension Description Example Command
path Top requested HTTP URIs / endpoints (default) caddy-analyze top /var/log/caddy/access.log
ip Top client IP addresses (identify scrapers & DoS) caddy-analyze top ip /var/log/caddy/access.log
ua Top User-Agent strings caddy-analyze top ua /var/log/caddy/access.log
status Top HTTP response status codes caddy-analyze top /var/log/caddy/access.log -b status
bandwidth Top paths sorted by total byte bandwidth caddy-analyze top bandwidth access.log -t 20

4. diff <baseline_log> <target_log> (Comparative Analysis)

Compares two log files side-by-side to detect RPS shifts, 5xx error spikes, latency regressions, and new failing URIs between deployments:

caddy-analyze diff baseline.log current.log

5. config [show|set|reset] (Persistent Configuration)

Manages default log source settings in local (./caddy-analyzer.json) or global (~/.config/caddy-analyzer/config.json) JSON config files:

# View active configuration and default source
caddy-analyze config show

# Set local default log source
caddy-analyze config /var/log/caddy/access.log

# Set global default log source
caddy-analyze config docker://my-caddy --global

# Reset / remove configuration file
caddy-analyze config reset

6. guard & block / unban (Firewall Management)

Monitors streaming logs and automatically adds offending IP addresses to Linux iptables DROP rules when attack thresholds are exceeded:

# Start automated firewall guard daemon (requires sudo)
sudo caddy-analyze guard --limit 50 --window 1m docker://my-caddy

# Manually block specific IP addresses
sudo caddy-analyze block 1.2.3.4 5.6.7.8

# Remove IP block from iptables
sudo caddy-analyze unban 1.2.3.4
