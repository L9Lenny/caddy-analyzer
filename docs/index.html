Overview

caddy-analyzer is a single-binary log analysis tool and security inspector written in Go. It parses Caddy v2 structured JSON access logs from files, standard input, Docker containers, Kubernetes pods, or systemd journalctl, producing terminal summaries, live streaming views, threat detection reports, and standalone HTML outputs.

Documentation Sections

Quickstart Commands

# Run terminal analysis on access log
caddy-analyze /var/log/caddy/access.log

# Enable threat detection engine
caddy-analyze --detect /var/log/caddy/access.log

# Stream colorized logs in real time from Docker
caddy-analyze tail docker://my-caddy

# Inspect top client IP addresses
caddy-analyze top ip /var/log/caddy/access.log

# Compare baseline log vs current log
caddy-analyze diff baseline.log current.log

# Save default log source configuration
caddy-analyze config /var/log/caddy/access.log
