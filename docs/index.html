⚡ Zero-Config Caddy v2 Log Diagnostics

The Ultimate Fast, Visual & Intelligent Access Log Analyzer

A zero-dependency CLI tool, 6-tab interactive TUI dashboard, threat detector, and offline HTML report generator designed natively for Caddy v2 structured JSON access logs.

curl -sSfL https://raw.githubusercontent.com/L9Lenny/caddy-analyzer/main/install.sh | sh

✨ Key Features

⚡

Native Caddy JSON Parsing

Parses Caddy v2 structured log schema out-of-the-box including nested TLS, headers, bytes, and float durations without regex configuration.

📊

Visual Terminal Bar Graphs

Displays Unicode proportion bars (████████░░) and Lipgloss status badges directly in your terminal output.

🛡️

Built-in Threat Detector

Scans for SQL Injection, XSS, Path Traversal, Log4j/JNDI, RCE, sensitive file probes (.env, .git), and automated scanners.

🚫

Real-time Firewall Guard

Monitors streaming logs and automatically blocks offending malicious IPs in real time via iptables thresholds.

🔍

Comparative Log Diff

Compare two log files side-by-side (before vs after deployment) to detect 5xx error spikes, RPS shifts, and latency regressions.

🐳

Multi-Source Streaming

Stream directly from local files, stdin pipe, Docker containers (docker://caddy), K8s pods (k8s://pod), or systemd journal.

🌐 Interactive HTML Report Live Preview

Generated standalone offline report (caddy-analyze -f html -o report.html)

📖 Subcommands & CLI Reference

Subcommand Example Description
caddy-analyze caddy-analyze /var/log/caddy/access.log Run instant terminal analysis report with Unicode bar graphs
tail caddy-analyze tail docker://my-caddy Stream and colorize Caddy access logs in real time
top caddy-analyze top path access.log Quick top-N metric inspector (path, ip, ua, status, bandwidth)
diff caddy-analyze diff base.log curr.log Compare two log files for RPS shifts, 5xx spikes & latency changes
guard caddy-analyze guard --limit 100 Auto-block malicious IPs in real time via iptables
