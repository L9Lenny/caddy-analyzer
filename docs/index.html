1. Synopsis & Overview

caddy-analyze is a command-line tool written in Go for parsing, analyzing, and monitoring Caddy v2 structured JSON access logs. It works out-of-the-box without custom log format definitions, parsing nested TLS handshakes, User-Agent classifications, latencies, status codes, and bandwidth metrics.

2. Installation

Linux & macOS (One-line installer)

curl -sSfL https://raw.githubusercontent.com/L9Lenny/caddy-analyzer/main/install.sh | sh

Windows PowerShell (One-line installer)

iwr -useb https://raw.githubusercontent.com/L9Lenny/caddy-analyzer/main/install.ps1 | iex

Go Toolchain

go install github.com/L9Lenny/caddy-analyzer/cmd/caddy-analyze@latest

Docker Container

docker run --rm -v /var/log/caddy:/logs ghcr.io/L9Lenny/caddy-analyzer /logs/access.log

3. Log Sources & Input Methods

caddy-analyze natively supports reading from multiple input sources without exporting files:

  • Local Log File / Glob: caddy-analyze /var/log/caddy/access.log or /var/log/caddy/*.log
  • Stdin Pipe: cat access.log | caddy-analyze -
  • Docker Container: caddy-analyze docker://my-caddy-container
  • Kubernetes Pod: caddy-analyze k8s://my-pod -n production
  • Systemd Journalctl: caddy-analyze journalctl://caddy.service

4. Subcommands Reference

Subcommand Description Example
caddy-analyze [source] Run analysis report. Auto-detects local log files if omitted. caddy-analyze /var/log/caddy/access.log
tail [source] Stream and colorize access logs in real time. caddy-analyze tail docker://my-caddy
top [dimension] [source] Quick top-N metric inspector (path, ip, ua, status, bandwidth). caddy-analyze top ip access.log
diff <log1> <log2> Compare two log files for RPS shifts, 5xx spikes, and latency changes. caddy-analyze diff base.log curr.log
guard [source] Monitor live log stream and auto-block malicious IPs via iptables. sudo caddy-analyze guard --limit 100
config [show|set|reset] Manage persistent default log source configuration. caddy-analyze config /var/log/caddy/access.log
block / unban Manually block or unban IP addresses via iptables. sudo caddy-analyze block 1.2.3.4

5. Security Threat Engine (--detect)

Pass the --detect / -d flag to inspect request URIs, headers, and User-Agents for common security attack patterns:

  • SQL Injection: UNION SELECT, OR 1=1, information_schema, pg_sleep()
  • Path Traversal & LFI: ../, /etc/passwd, php://filter, file:///
  • Cross-Site Scripting (XSS): <script>, javascript:, onerror=, alert()
  • Remote Code Execution (RCE): /bin/sh, powershell, whoami, eval()
  • Sensitive File Probes: .env, .git/config, wp-config.php, id_rsa
  • Automated Scanners: sqlmap, nikto, dirbuster, gobuster, nmap

6. TUI Dashboard & HTML Reports

Interactive TUI Dashboard (--watch)

caddy-analyze --watch /var/log/caddy/access.log

Navigable 6-tab terminal user interface: [1: Summary] [2: Realtime Stream] [3: Security Alerts] [4: Top IPs] [5: Top Paths] [6: User Agents].

Offline HTML Report Export (-f html)

caddy-analyze -f html -o report.html --detect /var/log/caddy/access.log
