caddy-analyzer

User Manual & Reference Guide for Caddy v2 Log Analysis and Security Inspection
⚡ Quickstart 📦 Install 🛠️ Commands 🔌 Log Sources 🛡️ Security 📊 Dashboards

⚡ 1. Quickstart (1-Minute Guide)

Analyze any Caddy v2 access log file instantly without configuration:

# 1. Run standard terminal analysis
caddy-analyze /var/log/caddy/access.log

# 2. Run with security threat detection (SQLi, XSS, Path Traversal)
caddy-analyze --detect /var/log/caddy/access.log

# 3. Filter slow requests (> 500ms) excluding search engine bots
caddy-analyze --slow 500ms --no-bots /var/log/caddy/access.log

📦 2. Installation

Install caddy-analyze as a single static binary on any platform:

Linux & macOS

curl -sSfL https://raw.githubusercontent.com/L9Lenny/caddy-analyzer/main/install.sh | sh

Windows (PowerShell)

iwr -useb https://raw.githubusercontent.com/L9Lenny/caddy-analyzer/main/install.ps1 | iex

Go (v1.22+)

go install github.com/L9Lenny/caddy-analyzer/cmd/caddy-analyze@latest

Docker

docker run --rm -v /var/log/caddy:/logs ghcr.io/L9Lenny/caddy-analyzer /logs/access.log

🛠️ 3. Command Reference

Command Purpose Example Usage
caddy-analyze Generate full terminal analysis report caddy-analyze access.log
top Inspect top metrics by dimension (path, ip, ua, status, bandwidth) caddy-analyze top ip access.log
tail Stream and colorize access logs in real time caddy-analyze tail docker://my-caddy
diff Compare two log files (detect 5xx spikes & RPS shifts) caddy-analyze diff baseline.log current.log
guard Auto-block attacking IPs in real time via iptables sudo caddy-analyze guard --limit 50
config Manage persistent default log source (local/global) caddy-analyze config /var/log/caddy/access.log
block / unban Manually block or unban IP addresses via iptables sudo caddy-analyze block 1.2.3.4

🔌 4. Log Sources & Input Formats

Pass any of the following input formats as positional arguments:

  • Local Log File: caddy-analyze /var/log/caddy/access.log
  • Glob Patterns: caddy-analyze /var/log/caddy/*.log
  • Standard Input (Stdin): cat access.log | caddy-analyze -
  • Docker Containers: caddy-analyze docker://my-caddy-container
  • Kubernetes Pods: caddy-analyze k8s://my-pod -n production
  • Systemd Journalctl: caddy-analyze journalctl://caddy.service

🛡️ 5. Threat Detector & Firewall Guard

Threat Engine (--detect)

Pass --detect / -d to enable deep packet analysis against malicious patterns:

  • SQL Injection: UNION SELECT, OR 1=1, information_schema
  • Path Traversal / LFI: ../, /etc/passwd, php://filter
  • Cross-Site Scripting (XSS): <script>, javascript:, onerror=
  • Remote Code Execution (RCE): /bin/sh, powershell, whoami
  • Sensitive File Discovery: .env, .git/config, wp-config.php
  • Scanner Tools: sqlmap, nikto, dirbuster, nmap

Real-time Firewall Guard Daemon (guard)

sudo caddy-analyze guard --limit 50 --window 1m docker://my-caddy

📊 6. Interactive Dashboards & Exports

Terminal TUI Dashboard (--watch)

caddy-analyze --watch /var/log/caddy/access.log

Interactive 6-tab terminal interface: [1: Summary] [2: Realtime Stream] [3: Security Alerts] [4: Top IPs] [5: Top Paths] [6: User Agents].

Offline Dark-Mode HTML Report (-f html)

caddy-analyze -f html -o report.html --detect /var/log/caddy/access.log
