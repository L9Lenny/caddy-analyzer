caddy-analyzer

Complete Technical Documentation & User Guide for Caddy v2 Access Log Diagnostics
Overview Installation Log Sources Subcommands Threat Detector TUI & HTML Reports

Overview

caddy-analyzer is a single-binary log analysis tool and security inspector written in Go. It parses Caddy v2 structured JSON access logs without requiring any regex or log format configuration.

📦 Installation

One-line static binary installer scripts for Linux, macOS, Windows PowerShell, Docker, and Go toolchain.

🔌 Log Sources

Stream directly from local log files, glob patterns, stdin pipe, Docker containers, Kubernetes pods, and journalctl.

🛠️ CLI Subcommands

In-depth guide for tail (real-time stream), top (metric inspector), diff (log comparison), and config.

🛡️ Threat Engine & Guard

Automated detection for SQLi, XSS, Path Traversal, Log4j, RCE, probes, and real-time firewall auto-blocking via iptables.

📊 Interactive UIs

6-tab terminal dashboard (--watch) and standalone dark-mode HTML web reports (-f html).

Quick Command Reference

# Run analysis on local file
caddy-analyze /var/log/caddy/access.log

# Enable threat detection engine
caddy-analyze --detect /var/log/caddy/access.log

# Stream colorized logs in real time
caddy-analyze tail docker://my-caddy

# Inspect top client IP addresses
caddy-analyze top ip /var/log/caddy/access.log

# Compare baseline vs target log file
caddy-analyze diff baseline.log current.log

# Save default log source configuration
caddy-analyze config /var/log/caddy/access.log
