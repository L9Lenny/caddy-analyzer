Zero Log Configuration

Parses Caddy v2's native JSON schema out-of-the-box including nested TLS versions, request headers, float durations, and status codes.

Built-in Security Inspector

Scans every line for SQLi, XSS, Path Traversal, Log4j, RCE, sensitive file probes (.env, .git/config), and scanner UAs.

Comparative Log Diff

Compare two log files side-by-side (caddy-analyze diff base.log curr.log) to pinpoint 5xx spikes and RPS regressions after deploys.

Real-time Guard & Streaming

Stream logs in real time (tail) or auto-block offending malicious IPs via iptables thresholds (guard).

Standalone Dark HTML Report Demo (caddy-analyze -f html) Self-contained SVG Charts

Command Reference

Command / Flag Usage
caddy-analyze <source> Analyze log file, stdin, Docker (docker://caddy), or K8s (k8s://pod)
caddy-analyze tail <source> Colorized real-time log viewer
caddy-analyze top <field> Inspect top metrics by dimension (path, ip, ua, bandwidth)
caddy-analyze diff <log1> <log2> Compare baseline vs current log file
--detect Enable anomaly & security threat detection engine
--slow 500ms Filter requests taking longer than specified duration
--no-bots Exclude search engines and crawler traffic
-f html -o report.html Generate single-file offline HTML report
