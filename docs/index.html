caddy-analyzer

Access log analyzer and security threat inspector for Caddy v2

caddy-analyzer is a single-binary log analyzer written in Go. It parses Caddy v2 structured JSON access logs from files, standard input, Docker containers, Kubernetes pods, or systemd journalctl, producing terminal summaries, live streaming views, threat detection reports, and standalone HTML outputs.

Installation

Linux & macOS (one-line installer):

curl -sSfL https://raw.githubusercontent.com/L9Lenny/caddy-analyzer/main/install.sh | sh

Windows (PowerShell):

iwr -useb https://raw.githubusercontent.com/L9Lenny/caddy-analyzer/main/install.ps1 | iex

Via Go toolchain:

go install github.com/L9Lenny/caddy-analyzer/cmd/caddy-analyze@latest

Via Docker:

docker run --rm -v /var/log/caddy:/logs ghcr.io/L9Lenny/caddy-analyzer /logs/access.log

Basic Usage

Run against a log file or stream:

# Basic terminal analysis
caddy-analyze /var/log/caddy/access.log

# Run security threat detector (SQLi, XSS, Path Traversal, probes)
caddy-analyze --detect /var/log/caddy/access.log

# Filter slow requests (> 500ms) and exclude bots
caddy-analyze --slow 500ms --no-bots /var/log/caddy/access.log

# Stream colorized logs in real time
caddy-analyze tail docker://my-caddy

# Compare baseline vs current log file
caddy-analyze diff baseline.log current.log

# Generate standalone offline HTML report
caddy-analyze -f html -o report.html /var/log/caddy/access.log

Subcommands & Options

Command / Flag Description
caddy-analyze [file|source] Run analysis report. Auto-detects local access.log if omitted.
tail [source] Stream and colorize logs in real time from file, Docker, K8s, or stdin.
top <field> [source] Show top metrics by dimension (path, ip, ua, status, bandwidth).
diff <log1> <log2> Compare two log files to detect 5xx error spikes, RPS shifts, and latency changes.
guard [source] Monitor live log stream and auto-block offending malicious IPs via iptables.
--detect, -d Enable threat detection (SQL Injection, XSS, RCE, LFI, scanner UAs).
--slow <dur> Filter requests taking longer than specified duration (e.g. 500ms, 1s).
--no-bots Exclude search engines and crawler traffic (Googlebot, Bingbot, etc.).
-f, --format <fmt> Output format: table, json, csv, html.

Security Signatures

When running with --detect, the engine inspects request URIs, headers, and User-Agents for:

  • SQL Injection: UNION SELECT, OR 1=1, information_schema, etc.
  • Path Traversal & LFI: ../, /etc/passwd, php://filter, etc.
  • Cross-Site Scripting (XSS): <script>, javascript:, onerror=, etc.
  • Remote Code Execution (RCE): /bin/sh, powershell, whoami, eval(), etc.
  • Sensitive File Probes: .env, .git/config, wp-config.php, id_rsa, etc.
  • Automated Scanners: sqlmap, nikto, dirbuster, nmap, etc.
