Installation Guide

Complete cross-platform installation methods for caddy-analyzer
Overview Installation Log Sources Subcommands Threat Detector TUI & HTML Reports

1. Linux & macOS One-Line Installer

Downloads the statically linked binary matching your OS (Linux / macOS) and CPU architecture (amd64, arm64, armv7, 386) and places it into /usr/local/bin/caddy-analyze:

curl -sSfL https://raw.githubusercontent.com/L9Lenny/caddy-analyzer/main/install.sh | sh

2. Windows PowerShell One-Line Installer

Downloads the static Windows binary (caddy-analyze.exe), extracts it to %LOCALAPPDATA%\caddy-analyze, and adds it to your user PATH:

iwr -useb https://raw.githubusercontent.com/L9Lenny/caddy-analyzer/main/install.ps1 | iex

3. Go Toolchain

If you have Go (v1.22+) installed on your system:

go install github.com/L9Lenny/caddy-analyzer/cmd/caddy-analyze@latest

4. Docker Container

Run without installing any dependencies on your host system by mounting your log directory:

# Run directly against a log file
docker run --rm -v /var/log/caddy:/logs ghcr.io/L9Lenny/caddy-analyzer /logs/access.log

# Stream from Docker container logs
docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/L9Lenny/caddy-analyzer docker://my-caddy-container

5. Manual Binary Download

Pre-compiled static binaries for all platforms are available on the GitHub Releases page:

  • caddy-analyzer_0.1.0_linux_amd64.tar.gz
  • caddy-analyzer_0.1.0_linux_arm64.tar.gz (Raspberry Pi 4/5, AWS Graviton)
  • caddy-analyzer_0.1.0_darwin_arm64.tar.gz (macOS M1/M2/M3/M4 Apple Silicon)
  • caddy-analyzer_0.1.0_darwin_amd64.tar.gz (macOS Intel)
  • caddy-analyzer_0.1.0_windows_amd64.zip (Windows 64-bit)

6. Verifying Installation

$ caddy-analyze --version
caddy-analyze version 0.1.0
